РУЛЕТКА НЕДА — Android-проект с автоматической сборкой APK

Игра находится в app/src/main/assets/index.html. Приложение запускает её офлайн в полноэкранном WebView; сохранения используют localStorage.

КАК ПОЛУЧИТЬ APK ЧЕРЕЗ GITHUB (БЕЗ ANDROID STUDIO):

1. Скачай RouletteNedaAndroid.zip и распакуй архив.
2. Открой https://github.com и войди в аккаунт (или создай его).
3. Создай новый репозиторий. Можно назвать его RouletteNeda. Для простоты выбери Public или Private — оба варианта поддерживаются.
4. На странице репозитория нажми Add file → Upload files.
5. Загрузи СОДЕРЖИМОЕ папки RouletteNedaAndroid, а не сам ZIP. Обязательно загрузи папку .github вместе с остальными файлами. Если сайт не показывает скрытую папку .github, включи отображение скрытых файлов в файловом менеджере или загрузи проект с компьютера через GitHub Desktop.
6. Нажми Commit changes.
7. Открой вкладку Actions. Выбери workflow “Build Roulette Neda APK”. Если автоматическая сборка не стартовала, нажми Run workflow → Run workflow.
8. Дождись зелёной галочки. Открой завершённый запуск сборки.
9. Внизу страницы найди Artifacts и скачай RouletteNeda-APK.zip.
10. Распакуй этот архив — внутри будет app-debug.apk. Перенеси APK на Android-телефон и открой его для установки. Android может попросить разрешить установку из выбранного источника.

ЧТО ДЕЛАЕТ АВТОМАТИЧЕСКАЯ СБОРКА:
Файл .github/workflows/build-apk.yml запускает Gradle в облаке GitHub Actions и публикует app-debug.apk как Artifact на 14 дней после сборки.

ПРИМЕЧАНИЕ:
Это debug APK для личного использования, не подписанный релизный APK для публикации в Google Play. Облачная сборка требует аккаунт GitHub и загрузку проекта в репозиторий.
